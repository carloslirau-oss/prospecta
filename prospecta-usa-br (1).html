Prospecção EUA · Diáspora brasileira

Encontre negócios de brasileiros nos EUA e chame no WhatsApp

Busca por negócios que se identificam como brasileiros no Google Maps (nome, categoria ou descrição) em qualquer cidade dos EUA, e manda sua oferta de site direto pro WhatsApp deles.

1. Configuração (uma vez só)

Precisa de uma chave com Maps JavaScript API e Places API (New) ativadas (Google Cloud Console). É gratuito até um volume mensal generoso, depois cobra por uso. Restrinja a chave por domínio quando for hospedar isso de verdade. A chave fica salva só no seu navegador (nunca é enviada pra mim ou pra qualquer servidor além do Google) — se usar computador compartilhado, desmarque a opção acima ou clique em "Esquecer chave" depois.

2. Buscar empresas

Essa lista já vem com os principais polos de comunidade brasileira nos EUA e Canadá. Remova cidades pra reduzir o número de buscas, ou adicione outras.

Faz uma busca separada pra cada combinação de sobrenome + cidade + nicho e junta tudo numa lista só, sem repetir. Pega principalmente negócios de serviço que usam o sobrenome do dono no nome da empresa (limpeza, construção, corretagem, etc.) — não pega empresas com nome de marca genérico.
